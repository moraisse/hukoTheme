# HUKO pets — Tema Shopify

## Como instalar
1. Faz o download do zip deste tema.
2. No Shopify admin: **Online Store → Themes → Add theme → Upload zip file**.
3. Publica ou pré-visualiza o tema.

## Configuração recomendada
- **Menus**: em Navigation, cria o menu `main-menu` (Cães, Gatos, Camas, Coleiras, Brinquedos, Higiene, Novidades) e o menu `footer` (Contacto, Envios, Devoluções, FAQ).
- **Imagens**: em Theme settings → Homepage, carrega a imagem do hero e a imagem editorial; adiciona imagens às coleções (usadas nos cards de categoria).
- **Produtos em destaque**: escolhe uma coleção em Theme settings → Homepage (por omissão usa a coleção "frontpage" / Home page).
- **Etiquetas**: adiciona a tag `novo` ou `mais-vendido` aos produtos para mostrar os selos nos cards.
- **Página Sobre**: cria uma página com o handle `sobre-nos` e atribui-lhe o template `page.sobre`.
